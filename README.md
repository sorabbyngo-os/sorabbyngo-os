# SORABBYNGO OS
> **Africa-First AI Operating System Kernel** — by Sorabbyngo Labs · *Rhythm of Digital Life*

## What is SORABBYNGO OS?
The custom Linux 6.19.10 kernel at the foundation of SORABBYNGO OS. Built with hardware cryptographic identity (NodeID), mesh network identity (Byngonet), and boot-critical drivers forced built-in for reliable operation in African deployment conditions.

## Stack
| Component | Detail |
|---|---|
| **Base kernel** | Linux 6.19.10 |
| **NodeID driver** | Hardware SHA-256 identity at /proc/sorabbyngo/nodeid |
| **Byngonet driver** | Mesh identity layer v0.2 |
| **Compiler** | GCC 12 — stable BTF, zero warnings |
